# Design

`AppIcon.png` is the icon's source artwork (full bleed). The app icon sets come from it:

- iPhone: `Apps/Mobile/Assets.xcassets/AppIcon.appiconset`, the artwork at 1024×1024 (iOS rounds the corners).
- Mac: `Apps/Host/Assets.xcassets/AppIcon.appiconset`, the artwork on Apple's macOS grid (an 824-point
  rounded square on a 1024 canvas, with a soft shadow), at every size from 16 to 1024.
